# Medibrid Partners

A modern healthcare platform connecting patients with clinics, featuring AI-powered chat assistance, location-based clinic discovery, and seamless dashboard management.

## 🚀 Features

- **Patient Dashboard**: Discover nearby clinics with interactive maps (Leaflet/OpenStreetMap) and custom banners.
- **Clinic Management**: Dedicated dashboards for clinics to manage their profile and seamless onboarding process.
- **MediBot Assistant**: AI-powered assistant for healthcare inquiries.
- **Firebase Integration**: Secure authentication, real-time database, and notifications capabilities.
- **Admin Panel**: Comprehensive administrative controls, including direct banner management and file uploads.
- **Real-time Messaging**: Built-in chat functionality for patient-clinic communication.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Backend/Services**: Node.js, Express (Custom Server), Firebase (Auth, Firestore, Storage)
- **Mapping**: Leaflet, React-Leaflet, OpenStreetMap

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up environment variables:
   Copy `.env.example` to `.env` and fill in your Firebase credentials and any other required API keys.

3. Start the development server:
   ```bash
   npm run dev
   ```

### Build for Production

```bash
npm run build
npm run start
```
